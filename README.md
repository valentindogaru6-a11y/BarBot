# BarBot

BarBot — будущий Telegram-бот для сотрудников бара. На текущем этапе проект
представляет собой универсальное, управляемое данными ядро каталога. Категории
и позиции добавляются в JSON, поэтому для расширения справочника не требуется
менять Python-код.

Проект рассчитан на Python 3.12. Telegram-слой на базе aiogram 3 будет добавлен
на следующем этапе.

## Архитектура

Код разделён по ответственности:

- `app/models/` — Pydantic-модели каталога, категорий, позиций и ингредиентов;
- `app/storage/` — безопасное чтение и валидация JSON;
- `app/services/` — независимая от Telegram логика каталога и поиска;
- `app/utils/` — общие текстовые функции;
- `app/handlers/` — место для будущих обработчиков aiogram;
- `app/keyboards/` — место для будущих клавиатур без бизнес-логики;
- `data/catalog.json` — единственный источник данных каталога;
- `tests/` — автоматические тесты моделей, хранилища и сервисов.

Обработчики не читают JSON напрямую. Поток данных выглядит так:

```text
data/catalog.json → storage → Pydantic models → services → Telegram layer
```

Хранилище на этом этапе работает только на чтение. `data/users.json` оставлен
для совместимости со структурой проекта, но нигде не используется.

## Формат `catalog.json`

Корневой объект содержит версию схемы и список категорий:

```json
{
  "version": 1,
  "categories": [
    {
      "id": "coffee",
      "name": "Кофе",
      "emoji": "☕",
      "description": "Кофейная карта",
      "sort_order": 20,
      "is_active": true,
      "items": [
        {
          "id": "example-item",
          "name": "Пример позиции",
          "short_description": "Краткое описание",
          "description": "Полное описание",
          "photo_file_id": null,
          "ingredients": [
            {
              "name": "Ингредиент",
              "amount": 18,
              "unit": "г"
            }
          ],
          "fields": {
            "cup": "200 мл",
            "temperature": "65 °C"
          },
          "steps": [
            "Тестовый шаг"
          ],
          "tags": [
            "пример"
          ],
          "sort_order": 10,
          "is_active": true
        }
      ]
    }
  ]
}
```

Поля `id` — стабильные строковые идентификаторы для программных ссылок и
callback-данных. Отображаемые `name` можно менять независимо от них.
`sort_order` управляет порядком, а `is_active` скрывает данные без удаления.
Поле `fields` принимает произвольный JSON-объект и хранит параметры,
специфичные для вина, кофе, коктейлей или любой новой категории.

Поиск выполняется только по активным категориям и позициям. Он не учитывает
регистр и ищет подстроку в названии, кратком и полном описании, тегах и
названиях ингредиентов.

## Установка

```bash
cd /opt/barbot
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Проверка

В активированном виртуальном окружении:

```bash
python -m pytest
python -m compileall app
```
