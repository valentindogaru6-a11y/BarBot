# Knowledge Evolution

## Purpose

Track how understanding changes over time so memory reflects the path to knowledge, not only the latest state.

## Standard Evolution Path

`Working hypothesis -> Confirmed -> Stable -> Possibly stale -> Superseded -> Archived`

Not every item must pass through every stage, but deviations should be explainable.

## Evolution Rules

- New uncertain findings begin as `Working hypothesis` in working memory.
- Verified reusable findings become `Confirmed`.
- Reused confirmed findings without contradiction become `Stable`.
- Dependency or evidence shifts move them to `Possibly stale`.
- Better replacements mark them `Superseded`.
- Historical-only items move to `Archived`.

## Recording Rule

When a meaningful evolution happens, record it in the relevant note, freshness manifest, or usage registry.
