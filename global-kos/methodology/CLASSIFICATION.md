# Memory Classification

## Shared Methodology

Reusable rules belong in:

- root `AGENTS.md`
- `memory/00-governing/`
- `global-kos/methodology/`
- the method decisions in `memory/01-canonical/decisions/`
- agent adapters in `global-kos/agents/`

## Local Project Knowledge

Facts about a specific target codebase belong only in that target's local `memory/` tree. This includes summaries, decisions, patterns, lessons, symbols, features, references, working notes, and freshness records.

Do not treat the KOS repository's own starter memory as facts about a future target project. Create or copy a separate local memory tree when onboarding that project.

## Reusable Templates

Keep reusable structures and domain-specific starting guidance under `global-kos/templates/`. Templates are prompts for discovery, not verified facts about any project.
