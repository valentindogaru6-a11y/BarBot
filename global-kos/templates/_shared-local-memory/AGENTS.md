# Local Project AGENTS Guidance

This file is guidance for composing project instructions; it is not a replacement project-root `AGENTS.md` and is not part of the `memory/` subtree.

Use the root Global KOS `AGENTS.md` as the protocol base for a new project. For an existing project, preserve its current instructions and merge in the relevant KOS rules. Point the result to `memory/MEMORY_INDEX.md` and `memory/00-governing/WORKFLOW.md`.

Domain template `AGENTS.md` files are optional supplements. Merge only their relevant discovery guidance; do not overwrite project instructions with them.
