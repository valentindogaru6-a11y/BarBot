Работать только внутри `/opt/barbot`.
Не читать и не изменять настоящий `.env`; не выводить секреты и реальные ID.
Не менять существующие стабильные ID каталога.
Каталог хранится в JSON; пользователи и изменяемые роли — в SQLite.
`super_admin` задаётся окружением и не изменяется через Telegram.
Не добавлять ORM, Redis или PostgreSQL без отдельного решения владельца.
Handlers не выполняют SQL напрямую; storage не содержит Telegram UI.
Все permissions должны вычисляться централизованно.
Каждый этап оформляется отдельным коммитом только по явной команде владельца.
После изменений запускать pytest, compileall, import check и git diff --check.
